# Bialet syntax plugin

Syntax highlighting for the [Bialet](https://bialet.dev) framework, based on the
[Wren](https://wren.io) language.

## Features

- Syntax highlighting for Wren and Bialet keywords, classes, and operators
- Inline HTML with interpolation
- Query syntax highlighting
- Line and block comments

## Installation

### VS Code

Install from the
[marketplace](https://marketplace.visualstudio.com/items?itemName=bialet.bialet-wren).

### Vim / Neovim

Install with [Plug](https://github.com/junegunn/vim-plug):

```vim
Plug 'bialet/bialet.vim'
```
